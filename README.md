#### 11.9.0 行为说明

- **自动更新**：脚本文件更名为 `xue-autowatch.user.js`（ASCII 文件名保证更新链接可靠），并写入 `@updateURL/@downloadURL`。从下面的安装链接装一次后，Tampermonkey 会定期自动检查更新；也可在 Tampermonkey 面板手动"检查更新"立即生效。
- **任务标题修复**：卡内文本"目标天数：无1973人已注册"这类元信息不再被当成任务名（此前影响面板显示与去重名单）；标题特征词扩充（培训/教育/课程/学习等）。
- 新增 `tests/scan.test.mjs`：用真实日志卡片数据验证扫描与完成判断，改扫描逻辑后跑 `node tests/scan.test.mjs` 回归。

#### 11.4.0 行为说明

- **无课可学提示**：自动学习找不到可学的任务时（全部学完、或已排除所有学完的任务），面板显示"无课可学：…"并停在「我的学习」页，不再乱跳。
- **列表页直接挑任务（11.5.0）**：在「我的学习→专属成长计划」的任务列表上直接读卡片的状态/进度文字（已完成/学习中/2/5 等），只点"未完成"的任务——不再逐个点进路径页确认是否学完。卡片状态认不出时才兜底进去看一次。
- **按钮配色**：全部按钮统一黑色底；「自动学习/自动考试」是开关（开启=常绿）；「复制日志/重置状态」是动作（点击时闪绿约1秒后恢复黑色）；倍速行不变。
- 修复：引导步骤状态被旧对象覆盖导致「专属成长计划」页签被每2秒无限重复点击的问题（现在页签点击有5次上限，激活后优先找任务卡片）。

#### 11.3.0 行为说明

- 面板按钮精简为：**自动学习 / 自动考试 / 复制日志 / 重置状态** + 倍速行。
- **按钮配色与倍速一致**：「自动学习」「自动考试」都是全局持久化开关——未开启=黑色，开启=绿色（所有标签同步显示）。
- **自动学习（总开关）**：点一下开启并自动带路开始学习；再点一下停止（当前视频会播完，但不再自动开新课/换任务）。未开启时纯手动浏览，翻看到已学完的路径页也不会被自动跳走。
- **自动接力**（开启自动学习时生效）：某任务视频全部学完且没开自动考试 → 自动回「我的学习」找**下一个还有视频没看的任务**继续学，剩余考试留待手动。
- 防循环保护：已学完的任务自动跳过；全部学完或引导失败时，开关自动回到关闭状态（按钮变黑）并明确提示。「重置状态」会清空已完成任务清单。

#### 11.1.0「自动学习」说明

点击面板新增的蓝色「**自动学习**」按钮，无论当前在哪个页面：

- 已在**路径页** → 直接开始自动学习；
- 在**我的学习页** → 自动点「专属成长计划」→ 自动点具体任务 → 开始学习；
- 在**其它页面**（首页等）→ 上次的路径没学完就直接回上次的路径页；已学完则去我的学习页找新任务；
- 已在**课程播放页** → 提示"学习中"，不打扰。

引导过程状态跨页面保存、面板实时显示步骤；90 秒未到达自动放弃，说明原因并回退到上次的路径页。若网站改版导致入口找不到，面板会明确提示，手动进入一次即可。

#### 11.0.0 合并说明

- 原「阳光学习平台16倍速」独立脚本已合并进来，**请到 Tampermonkey 管理面板删除旧的16倍速脚本**（若保留会双重加速，脚本检测到后会在面板警告）。
- 悬浮面板新增「倍速」一行：**关 / 2x / 4x / 8x / 16x**，点击立即生效并全局记忆（所有标签页同步），默认 16x。
- 倍速引擎**仅在课程播放页挂钩**（计时器/时钟加速），路径/考试/结果页自动停用并还原钩子——考试的"≥1分钟交卷"等节奏不受影响。
- **片尾降速保持现状**：视频最后 8 秒自动降为 1 倍速自然播完，平台自己的上报逻辑按真人节奏登记完成；播完后等待目录状态确认"已完成"才切下一节（最多片尾重播2次，仍不确认则跳过，绝不来回跳）。全程不伪造任何完成请求。

#### 10.4.0 修复内容（保留说明）

**看课（配合倍速）**
- **片尾自动降 1 倍速**：高倍速下片尾"一闪而过"导致平台来不及登记、该节永远不变"已完成"——这是"某视频卡在最后几秒、课程里来回切换跳转"的根因。
- **播完等平台确认**：等不到就把片尾 10 秒按 1 倍速重播（最多 2 次）；仍不确认则标记跳过。
- **卡死自愈**：播放 4 分钟无进展自动刷新；播放页 2 分钟无视频元素自动刷新。
- 完课后播放页不再强制跳回路径；补上"进页冷静期"防秒判完课。

**考试**
- **自动考试开关全局持久化**：旧版只改当前标签内存，新开的考试/结果标签里开关是关的，流水线实际断链。现在所有标签同步，再点一次关闭。
- **已通过的考试不再自动重考**。
- **选项字母解析修复**：兼容 A / A. / A、 / 正确 / 错误 等写法。
- 试卷懒加载自动更新题数。

**架构 / 多标签**
- 跨标签真实时钟（`realNow` / `__xueRealNow`），心跳/冷却/租约时间戳不再被加速时钟搅乱。
- 单操作标签租约：全站同一时刻只允许一个标签执行点击，杜绝重复开课/开考。
- SPA 类型切换整页重启，清理僵尸定时器/心跳。
- 已完成课程本地清单过滤；播放心跳节流。

## 使用方式

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击安装脚本（装这一次之后**自动更新**，以后不用再手动装）：
   [https://raw.githubusercontent.com/hsy66/metaphysics/main/xue-autowatch.user.js](https://raw.githubusercontent.com/hsy66/metaphysics/main/xue-autowatch.user.js)
   （本地开发可直接打开 `xue-autowatch.user.js` 复制进 Tampermonkey）
3. **删除旧的「阳光学习平台16倍速」独立脚本和旧版手动创建的看课脚本**（如安装过）
4. **关闭所有旧的 xue.sinosig.com 标签页**（旧版本残留的定时器/心跳会干扰新版），重新打开
5. 访问 `https://xue.sinosig.com/`：
   - **点「自动学习」一键开始**：任意页面点击，自动带路到路径页并开始学习
   - 面板「倍速」行选择 关/2x/4x/8x/16x（全局记忆，立即生效）
   - 需要自动考试时点「自动考试」（全局开关，再点一次关闭）
   - 出问题时点「复制日志」留证

> 💡 **建议**：日常使用建议 2x 或 4x，既能提升效率又不易被平台检测；16x 仅在需要快速刷完视频时使用。片尾最后 8 秒无论选哪个倍速都会自动降为 1x 自然播完。
